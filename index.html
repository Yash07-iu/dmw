🔥 LAB 1 - Data Understanding and Classification

Read the given dataset using Pandas.

Display first few records of the dataset.

Analyze structure using info() and describe().

Identify each attribute as qualitative or quantitative.

Determine whether quantitative data is discrete or continuous.

Identify the scale of measurement (Nominal, Ordinal, Interval, Ratio).

Store results in a structured format.

import pandas as pd
import numpy as np

df = pd.read_csv("dataset.csv")

print(df.head())
print(df.info())
print(df.describe())

def classify_data_type(series):
    if series.dtype == 'object':
        return "Qualitative"
    elif np.issubdtype(series.dtype, np.integer):
        return "Quantitative - Discrete"
    elif np.issubdtype(series.dtype, np.floating):
        return "Quantitative - Continuous"
    else:
        return "Unknown"

def identify_scale(column):
    col = column.lower()
    if col in ["name", "gender", "course", "city"]:
        return "Nominal"
    elif col in ["year"]:
        return "Ordinal"
    elif col in ["student_id", "age", "marks", "attendance"]:
        return "Ratio"
    return "Unknown"

results = []
for col in df.columns:
    data_type = classify_data_type(df[col])
    scale = identify_scale(col)
    results.append([col, data_type, scale])

classification_df = pd.DataFrame(results, columns=["Attribute","Data Type","Scale"])

print(classification_df)

classification_df.to_csv("classification_result.csv", index=False)

🔥 LAB 2 - Data Cleaning Techniques

Read the dataset containing missing and inconsistent values.

Display dataset structure and summary.

Replace blank values with NaN.

Identify numerical and categorical columns.

Fill missing numerical values using median.

Fill missing categorical values using mode.

Detect and correct noisy data (invalid values).

Fix inconsistent data (formatting issues).

Clean column names.

Save the cleaned dataset.

import pandas as pd
import numpy as np

df = pd.read_csv("dataset.csv")

print(df.head())
print(df.info())
print(df.describe())

df.replace("", np.nan, inplace=True)

num_cols = df.select_dtypes(include=['int64','float64']).columns
for col in num_cols:
    df[col] = df[col].fillna(df[col].median())

cat_cols = df.select_dtypes(include=['object']).columns
for col in cat_cols:
    df[col] = df[col].fillna(df[col].mode()[0])

df.loc[(df['Age'] < 17) | (df['Age'] > 25), 'Age'] = df['Age'].median()
df.loc[(df['CGPA'] < 0) | (df['CGPA'] > 10), 'CGPA'] = df['CGPA'].mean()

df['Gender'] = df['Gender'].str.capitalize()
df['Caste_Category'] = df['Caste_Category'].str.upper()
df['City'] = df['City'].str.strip().str.title()

df.columns = df.columns.str.lower().str.replace(" ", "_")

print(df.isnull().sum())

df.to_csv("cleaned_data.csv", index=False)

🔥 LAB 5 - Dimensionality Reduction using PCA

Load dataset using Pandas.

Handle missing values.

Separate features from dataset.

Standardize the dataset.

Apply Principal Component Analysis (PCA).

Transform data into principal components.

Analyze explained variance.

Visualize reduced data using scatter plot.

import pandas as pd
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

df = pd.read_csv("dataset.csv")

print(df.head())

df.dropna(inplace=True)

X = df.select_dtypes(include=['int64','float64'])

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)

print(pca.explained_variance_ratio_)

plt.scatter(X_pca[:,0], X_pca[:,1])
plt.show()

🔥 LAB 6 - Association Rule Mining using Apriori Algorithm

Load transactional dataset.

Convert data into suitable format (binary/one-hot encoding).

Apply Apriori algorithm.

Generate frequent itemsets using minimum support.

Generate association rules.

Set confidence and lift thresholds.

Filter strong rules.

Interpret relationships between items.

import pandas as pd
import numpy as np
from mlxtend.frequent_patterns import apriori, association_rules

df = pd.read_csv("dataset.csv")

print(df.head())

df = df.astype(bool)

frequent_itemsets = apriori(df, min_support=0.5, use_colnames=True)

rules = association_rules(frequent_itemsets, metric="confidence", min_threshold=0.5)

print(rules)

import numpy as np
